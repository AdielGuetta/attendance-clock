# הצגה של עד 10 דקות: תסריט לתרגול

הזמנים בסוגריים הם יעד. סה"כ כ-9.5 דקות, עם חצי דקה רזרבה.
הסבר מלא במילים פשוטות נמצא ב-[GUIDE.md](GUIDE.md), ושני תרגילי שינוי ב-[PRACTICE.md](PRACTICE.md).

## הכנה (לפני שמתחילים, לא נספר בזמן)

1. Docker Desktop פתוח ומראה "Engine running".
2. מתיקיית המאגר: `docker compose up -d --wait`, ואז פותחים את http://localhost:8080.
3. פותחים לשוניות מוכנות:
   - GitHub, לשונית Actions: הריצה האחרונה ירוקה.
   - הקובץ `backend/Attendance.Api/Data/AttendanceRepository.cs`, בפונקציה `PunchAsync`.
4. אם עובד 1 נשאר במשמרת מתרגול קודם, מחתימים לו יציאה.

---

## 1. מה בניתי (דקה)

- שעון נוכחות: עובד מחתים כניסה ויציאה ורואה את המשמרות שלו, ומנהל רואה דוח.
- שלושה חלקים: React בדפדפן, שרת ASP.NET Core, ומסד SQL Server. הכול רץ עכשיו ב-Docker, בסביבת Linux.
- **הדרישה המרכזית:** השעה של כל החתמה מגיעה משירות זמן חיצוני של ציריך, ולא מהמחשב.
- הקושי האמיתי הוא לא המסכים, אלא מה שמשתבש: השירות נופל, לחיצה כפולה, שתי בקשות יחד, רענון באמצע, ומעבר שעון.

## 2. הדגמה חיה (2.5 דקות)

1. מסך עובד, נועה כהן: **החתמת כניסה**. מראים את ההודעה עם השעה מציריך, ושהטיימר רץ.
2. **מרעננים (F5).** הטיימר ממשיך מאותה שעה: המצב שמור בשרת, לא בדפדפן.
3. **החתמת יציאה.** המשמרת עוברת לטבלה עם המשך ומקור השעה.
4. מסך **מנהל**: היום, שבוע, ייצוא CSV. המשמרת שהרגע נרשמה מופיעה.
5. אם יש זמן: לשונית שנייה, החתמה באחת והשנייה מתעדכנת לבד.

## 3. מה קורה מאחורי הכפתור (2 דקות)

מראים את `PunchAsync`. חמישה צעדים:

1. **"כבר קיבלתי את זה?"** לכל לחיצה יש מספר זיהוי (`requestId`). אם הוא כבר שמור, מחזירים את אותה תשובה ולא רושמים שוב.
2. **בדיקה מהירה:** פעולה שבטוח תידחה לא פונה בכלל לשירות הזמן.
3. **שעה מהשירות החיצוני, לפני שנועלים משהו**, כדי שהמתנה לרשת לא תתקע עובדים אחרים.
4. **נועלים את שורת העובד**, בודקים שוב ושומרים משמרת והחתמה יחד.
5. **רשת ביטחון במסד:** אינדקס שלא מאפשר שתי משמרות פתוחות לאותו עובד, גם אם יש באג בקוד.

משפט אחד על `RecordedAtUtc`: זו השעה של שעון המסד כשהשורה נכתבה, לביקורת בלבד. שעת ההחתמה היא `AtUtc`, מהשירות החיצוני.

## 4. מקרי קצה (2.5 דקות)

| מקרה | הפתרון | איך מראים |
|------|--------|-----------|
| שירות הזמן נופל | ספק גיבוי, ניסיון חוזר, ואם הכול נכשל: הודעה ושום דבר לא נשמר | **חי:** `compose.outage.yaml` (ראו למטה), או הבדיקה `ExternalTimeServiceTests` |
| לחיצה כפולה | הכפתור ננעל, ואותו מזהה מחזיר את אותה קבלה | הבדיקה בדפדפן: שלוש לחיצות יצרו בקשה אחת |
| בקשות מתחרות | נעילת שורה ואינדקס ייחודי | בדיקה עם 5 בקשות במקביל: רק אחת מצליחה |
| שני ספקים עם שעונים שונים | כניסה מוקדמת מסוף המשמרת הקודמת נדחית | **תיקון 11, שנמצא בבדיקת ההתאמה למטלה** |
| רענון באמצע שליחה | המזהה נשמר בדפדפן, ושואלים את השרת עד 30 שניות | **באג שמצאתי בבדיקה בדפדפן ותיקנתי** (תיקון 8) |
| שעון קיץ וחורף | שומרים UTC, משך = הפרש אמיתי, גבול יום = חצות בציריך | משמרת 22:00 עד 06:00 בליל המעבר = **9 שעות** |

**הדגמת נפילה חיה (אם יש זמן, כ-40 שניות):**

```bash
docker compose -f compose.yaml -f compose.outage.yaml up -d --wait app
```

לוחצים כניסה, ומופיעה הודעה ש"שירות השעה החיצוני אינו זמין". מחזירים עם `docker compose up -d --wait app` ולוחצים "נסו שוב". זה נשמר עם אותו מזהה.

  - הרצה של כל המערכת ב-Docker מעותק נקי לפי ה-README.
  - דפדפן אמיתי (Chromium) שמחתים כניסה, מרענן, מחתים יציאה ובודק את הדוח.
  - הדגמת נפילה של שירות הזמן.
- התיעוד: מה נבדק ב-`docs/TESTING.md`, ו-12 תיקונים ב-`docs/FIXES.md`.
- **בכנות:** במחשב שלי Smart App Control חוסם הרצה של .NET שנבנה מקומית. לא כיביתי אותו, אלא הרצתי את המערכת ב-Docker.

## שאלות שכדאי להתכונן אליהן

- **למה לא לקחת את השעה מהשרת כשהשירות נופל?** הדרישה היא שעה חיצונית, ושעון שרת שמכוון לא נכון היה נרשם בשקט. עדיף להיכשל בגלוי ולאפשר ניסיון חוזר.
- **מה אם שני השירותים מחזירים שעות שונות?** השעה נשמרת עם המקור שלה. אם היא לא הגיונית ביחס למשמרות של העובד (יציאה לפני כניסה, או כניסה לפני סוף המשמרת הקודמת), ההחתמה נדחית ומנסים שוב.
- **מה קורה אם שני שרתים רצים במקביל?** הנעילה היא במסד ולא בזיכרון של השרת, ולכן היא עובדת גם בין מופעים.
- **מה ההבדל בין `AtUtc` ל-`RecordedAtUtc`?** הראשונה היא שעת ההחתמה מהשירות, והשנייה היא שעת הכתיבה לפי שעון המסד, לביקורת.
- **איך הייתם מוסיפים תיקוני מנהל?** טבלה נפרדת של תיקונים, עם מי תיקן ולמה, בלי לשנות את ההחתמה המקורית.
